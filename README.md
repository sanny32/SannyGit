# SannyGit

A desktop Git client for Windows, Linux and macOS, built with Rust and egui and inspired by SmartGit. Under development.

Requires Rust 1.95+ and Git 2.36+ on `PATH`.

## Run

```sh
cargo run
```

## Check

```sh
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build
```
