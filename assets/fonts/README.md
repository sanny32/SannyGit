# Source Sans 3

Source Sans 3 version 3.052, by Adobe.

Source: https://github.com/adobe-fonts/source-sans/tree/3.052R

The unmodified Regular and Semibold TTF files are embedded in the application.
They are distributed under the SIL Open Font License 1.1; see `OFL.txt`.

SannyGit uses Inter 4.001 on Windows. The Regular and SemiBold TTF files come
from [PhotoCraft's font assets](https://github.com/storytold/photocraft/tree/main/assets/fonts)
and are distributed under the SIL Open Font License 1.1. See `OFL-Inter.txt`.
Source Sans 3 is used on other platforms and as a fallback on Windows. The diff
uses a monospace font.

Text uses egui's font hinting in both themes. Inter uses fractional horizontal
glyph positions. Source Sans 3 uses horizontal grid fitting.
